Data Notes

数据说明

当前浏览器中的游客模式数据会在这里汇总，并用于后续账号导入同步。

  • 导出只针对当前项目，执行前请先确认项目选择器指向正确项目。
  • 工作区导入导出会同时包含任务项目和 App 版本数据，不会把两块内容混在一条记录里。
  • 导入 JSON 时不会覆盖整库，而是把 JSON 内容追加到当前工作区。
  • 游客模式与账号模式的数据是分离的，登录后不会自动合并本地数据。
  • 如果需要把游客数据写入当前账号，请切到“账号与同步”页面显式执行导入。
