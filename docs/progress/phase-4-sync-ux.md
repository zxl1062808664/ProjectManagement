## Notes

- 游客数据到云端的导入保持显式触发，不做隐式自动 merge。
- 前端已补齐空状态、Toast 反馈、筛选摘要和游客导入提示。
- 任务总览页移除了“使用方式”说明区，把全局任务统计与状态分布并排展示，并将项目任务摘要改成默认折叠的项目卡片。
- 项目管理页已独立承接项目创建、修改、归档和标签维护，任务管理与 App 版本管理都改为只消费已有项目。
- 左侧现已新增独立 `Kiosk 统计` 模块，可直接在当前项目下维护 Kiosk 列表、打印机连接信息和远控资料；新建面板默认收起，仅在点击“新建 Kiosk”后展开，`Kiosk 平台` 与 `远控平台` 支持预设下拉和“其他”自定义输入，列表也支持按地区分类下拉筛选，并将编辑区与列表区压缩为更紧凑的纵向节奏。
- 左侧导航已统一收拢为“项目管理”分类，包含项目管理、任务总览、任务管理、Kiosk 统计、版本总览和 App 版本管理六个入口。
- App、版本和 Kiosk 记录现已挂在项目之下，游客模式与云端模式下的工作区导入导出也同步升级为项目内嵌 Kiosk、App / 版本数据的结构，并兼容旧版独立 App 数据。
- App 版本管理里的版本列表现已同步显示当前所选 App 的包名 / 标识输入框，方便在核对版本时直接查看和复制。
- 账号与同步页新增白天/晚上模式切换，主题状态使用浏览器本地存储持久化，并同步影响全局界面观感。
- 左侧功能导航栏继续收紧品牌区、状态卡和分类按钮的纵向空间，占用高度更低。
- 左侧新增独立“常用工具”分类，除工具台页外，还补齐工作区刷新、项目详情跳转、摘要复制、待办清单复制、项目 JSON 复制和完整工作区导出等侧边快捷入口。
