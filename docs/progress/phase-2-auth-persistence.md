# Phase 2: Auth Persistence

- [x] T2.1 设计并初始化 SQLite schema
  验收标准：用户、会话、项目、任务、子任务、标签和关联表可初始化。

- [x] T2.2 实现注册/登录/登出/会话校验 API
  验收标准：用户可注册登录，服务端可识别和销毁会话。

- [x] T2.3 构建前端认证界面和会话恢复
  验收标准：刷新后可恢复登录态，未登录和已登录视图分离。

- [x] T2.4 打通受保护接口与错误处理
  验收标准：认证失败、参数失败和服务端错误均有可见反馈。

## Notes

- 会话应以后端记录为准，不能把浏览器本地缓存误当成鉴权真相来源。
- 已使用 `node:sqlite` 初始化完整 schema，并用 HttpOnly cookie 建立会话。
- 已新增前端登录/注册面板、会话恢复、登出和云端状态提示。
- 当前 Node 24 中 `node:sqlite` 仍带 experimental warning，但功能已可运行且测试通过。
