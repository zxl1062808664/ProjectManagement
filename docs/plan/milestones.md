# 里程碑

## M1: 可启动的全栈骨架

达成条件：

- Node.js 项目结构完成
- Express 服务可启动
- 页面可通过服务端静态托管访问
- 具备基础脚本和 README

对应阶段：

- Phase 1

## M2: 可登录的个人工作区

达成条件：

- 用户可注册、登录、登出
- 服务端会话有效
- SQLite schema 初始化完成
- 登录后可进入受保护工作区

对应阶段：

- Phase 2

## M3: 可用的多项目任务系统

达成条件：

- 一个账号可管理多个项目
- 任务、子任务、标签和筛选功能可用
- 前端主要操作改为 API 驱动
- 可导出和导入 JSON 数据

对应阶段：

- Phase 3

## M4: 游客/云端双模式可切换

达成条件：

- 未登录可本地使用
- 登录后切换到云端工作区
- 本地游客数据可显式导入账号
- UI 已覆盖多项目、标签、子任务与同步状态

对应阶段：

- Phase 4

## M5: 可交付版本

达成条件：

- 核心 API 有自动化测试
- 有演示数据或演示账号
- 文档覆盖启动、部署、备份和使用
- 已完成最终 QA 和问题整理

对应阶段：

- Phase 5
