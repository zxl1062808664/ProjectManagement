## 阶段依赖结论

- Phase 1 是所有工作的底座，不能跳过。
- Phase 2 必须在数据库和认证边界稳定后才能推进领域 API。
- Phase 3 是产品能力的主体，Phase 4 的同步和 UI 扩展依赖它完成。
- Phase 5 不能只做文档，必须建立最少可用的自动化验证，否则回归风险过高。
